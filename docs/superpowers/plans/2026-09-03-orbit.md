# Orbit product implementation plan

> **For agentic workers:** Use subagent-driven-development for delegated units. Execute continuously in this task; the user approved development. Each unit includes meaningful tests and a review.

**Goal:** Deliver the specified Orbit application, faithful desktop/mobile UI, persistent personal use and isolated demo, runnable via Docker and prepared for two online deployments.
**Architecture:** React SPA and modular FastAPI REST API in one multi-stage Docker artifact; PostgreSQL source of truth. OIDC PKCE for personal use, expiring isolated demo sessions only when APP_MODE=demo. Optional external integrations do not block the free core.
**Tech Stack:** Python 3.14, PostgreSQL 18, Node 24, React/TypeScript/Vite, TanStack Query, SQLAlchemy/Alembic, Docker Compose.
**Spec:** docs/specification.md, docs/deployment-requirements.md; docs/design/design.json and originals.

## Global Constraints
- pt-BR product, English technical documentation. Exact approved design adapted to real data and responsive behavior.
- No float money. Positive integer minor units; owner-scoped queries, UUIDs, optimistic versions, UTC technical instants/local DATE domain values.
- No own password storage. Verify OIDC signed access tokens against configured issuer/audience/JWKS. PKCE browser flow. Personal deployment NEVER accepts demo credentials.
- Same code, two URLs/installations and isolated databases. Personal MUST be accessible online from mobile. Free core, Docker mandatory, no cloud service purchased or provisioned without available authorization/account.
- Complete M1–M9, and optional M10 provider integration with explicitly simulated demo. Do not misrepresent unavailable credentials as a working external integration.
- Work only in assigned files; controller owns web and container/CI/docs; backend worker owns backend. No descendants. Read functional specification before implementation.
- Tests first for critical rules. Real PostgreSQL integration tests, responsive end-to-end journeys, production build/container smoke; audit remaining limits honestly.
