# Product rulings

- Personal and demo are both online deployments of the same artifact, with separate databases. Local Compose remains a development/self-host option, not the only personal experience.
- Installments distribute the remainder one cent at a time to the earliest installments: 1001/3 = 334,334,333. This satisfies exact totals and <=1-cent differences; count above total cents is rejected. This resolves the contradictory pseudocode in v1.1.
- Financial recurrence uses an idempotent CLI horizon extension, suitable for a host scheduler. No permanent Redis dependency for the core.
- Dashboard suggested workout means a recent/available routine, not AI.
- OIDC is required for personal mode. Demo uses isolated expiring bearer sessions only in separately configured demo instances.
- Dark Stitch visual takes precedence over earlier optional-dark wording. Mobile shares the application and all persisted data.
- External publication needs accessible provider accounts; deployment files and local Docker validation do not constitute a public deployment.
